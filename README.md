# 神猫相机（桌面小程序）

复古风格的美颜相机，带可爱卡通小猫图标、木板/相机/胶片装饰与眨眼等动态效果；支持「深夜模式」（深色界面 + 睡猫 + 月亮/路灯装饰 + 低照度增强）。

## 运行
- 直接双击 `dist/神猫相机.exe`（已打包好的单文件）。
- 拍照后照片保存在 **exe 同级的 `照片` 文件夹**里。

## 功能
| 模块 | 内容 |
|------|------|
| 摄像头 | 实时预览（镜像）、FPS/人脸数/分辨率显示 |
| 人脸识别 | YuNet 深度学习检测（`models/face_detection_yunet_2023mar.onnx`） |
| 美颜 | 美白、瘦脸（局部形变）、大眼 —— 程度滑杆可调 |
| 画质增强 | 清晰度、锐化（反锐化掩模）、亮度、对比度、饱和度 |
| 滤镜 | 程序化生成 **360 种**（5 风格 × 9 色温 × 8 色调）+ 原图 |
| 相机参数 | 快门(曝光) / ISO(增益) / 白平衡 / 聚焦，支持「自动 / 手动」切换；硬件不支持时自动用软件增益兜底 |
| 深夜模式 | 一键切换深色主题：夜间界面配色、睡眠小猫、月亮/路灯装饰、星星闪烁；相机自动增强暗光画面（增益上限提升、目标亮度提高，保证夜间清晰度） |

## 从源码运行
```bash
python beauty_camera.py
```

## 重新打包 exe
```bash
python build_exe.py
```

## 依赖
- Python 3.13、opencv-python(cv2)、numpy、Pillow、tkinter(标准库)、PyInstaller

## 说明
- 关键依赖 `cv2 5.0` 已移除自带的 Haar 人脸模型，故人脸检测使用 YuNet ONNX（已随包下载）。
- 手动曝光/ISO 等参数依赖具体摄像头硬件能力，能设则设，设不了会自动退回软件增益，保证效果始终生效。
